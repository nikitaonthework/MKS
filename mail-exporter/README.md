# Экспорт почты sestroclinic.ru (e.mail.ru / VK WorkMail) в Thunderbird

Скрипт для Tampermonkey (или Greasemonkey/Violentmonkey), который скачивает
письма из веб-интерфейса e.mail.ru, если IMAP не работает, и сохраняет их
в файлы `.mbox` — их можно импортировать в Thunderbird расширением
**ImportExportTools NG**.

## Важное предупреждение

У e.mail.ru нет официального открытого API для этой задачи — скрипт
подсматривает за запросами, которые сам сайт делает в браузере, и
повторяет их программно. Названия параметров и структура ответов не
документированы, поэтому:

- скрипт **сам не угадывает ссылки** — он ждёт, пока ты откроешь папку и
  письмо в интерфейсе, и запоминает реальные запросы;
- вложения переносятся, только если в ответе API есть прямая ссылка на
  файл — если нет, скрипт пропустит вложение и напишет об этом в лог;
- если письма выгружаются с пустыми полями (тема/отправитель) — включи
  режим `debug` в панели, открой консоль браузера (F12) и пришли мне,
  что там в `raw message json` — поправлю сопоставление полей.

Это разовый инструмент для переноса почты, а не постоянное решение —
после переноса стоит разобраться, почему не работает IMAP.

## Установка

1. Поставь расширение **Tampermonkey** в Chrome:
   https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. Открой панель Tampermonkey → «Создать новый скрипт».
3. Удали содержимое по умолчанию, вставь целиком файл
   [`mailru-email-exporter.user.js`](./mailru-email-exporter.user.js) из этой папки.
4. Сохрани (Ctrl+S).

## Как пользоваться

1. Зайди на https://e.mail.ru и открой ящик (в твоём случае —
   `pavlov@sestroclinic.ru`, через админ-доступ `it@sestroclinic.ru`).
2. В правом нижнем углу появится панель **«📬 Экспорт почты
   sestroclinic»**.
3. Открой папку «Входящие» и полистай список писем вниз (прокрути хотя
   бы на 1–2 экрана) — так скрипт увидит запрос списка писем и поймёт,
   какой параметр отвечает за смещение (offset/страницу).
4. Открой любое письмо целиком — так скрипт увидит запрос содержимого
   письма.
5. В панели в статусе должно появиться:
   - `Шаблон списка писем: ✅ найден`
   - `Шаблон письма: ✅ найден`
6. Ниже появится список папок, которые ты уже открывал (Входящие,
   Отправленные, и т.д. — открой каждую папку по очереди тем же
   способом: зайти + прокрутить список).
7. Нажми **⬇ Экспорт** напротив нужной папки. Скрипт начнёт скачивать
   письма по одному через тот же API, собирать их в `.mbox` и каждые
   ~300 писем сохранять файл через обычное скачивание браузера
   (`Входящие_part1.mbox`, `Входящие_part2.mbox`, ...).
8. Если сервер попросит паузу (слишком много запросов) — скрипт сам
   подождёт и повторит. Если токен авторизации протухнет — панель
   покажет "⏸ на паузе", открой любое письмо руками и нажми
   **▶ Продолжить**.
9. Экспорт можно прервать в любой момент кнопкой **⏹ Остановить всё** —
   прогресс по каждой папке сохраняется в IndexedDB браузера, при
   следующем запуске (той же вкладки/профиля) экспорт папки продолжится
   с того же места, а не с начала.

Повтори для каждой папки (Входящие, Отправленные, Черновики, Спам,
Корзина — по необходимости).

## Импорт в Thunderbird

1. Поставь расширение **ImportExportTools NG** в Thunderbird:
   https://addons.thunderbird.net/thunderbird/addon/importexporttools-ng/
2. Создай в Thunderbird локальную папку под архив (например,
   `Локальные папки → Входящие_sestroclinic`).
3. Правой кнопкой по папке → **ImportExportTools NG → Импорт mbox-файла
   (import mbox file)**.
4. Выбери все скачанные `*_part*.mbox` файлы для этой папки (можно
   выбрать несколько сразу) — они импортируются друг за другом в одну
   папку.
5. Повтори для каждой исходной папки почты.

## Если что-то пошло не так

- **Панель не появилась** — проверь, что Tampermonkey включён для сайта
  e.mail.ru (иконка расширения → «Разрешить»), и что скрипт активен на
  вкладке «Панель управления» Tampermonkey.
- **Папки не появляются** — убедись, что реально прокручиваешь список
  писем (подгружаются новые письма), а не просто открываешь папку с уже
  загруженным первым экраном.
- **В .mbox письма без темы/текста** — включи debug-чекбокс в панели,
  открой DevTools (F12) → Console, найди строку `[MKSMailExport] raw
  message json` и посмотри реальную структуру ответа — пришли её мне,
  я поправлю извлечение полей под точный формат ответа.
- **Вложения не переносятся** — то же самое: включи debug и посмотри в
  консоли, как называется поле со ссылкой на файл вложения.
