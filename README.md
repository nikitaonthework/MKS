# IT Service Desk — тикет-система для IT-отдела клиники

Веб-приложение на PHP + MySQL для приёма и обработки заявок сотрудников
клиники в IT-отдел, плюс Telegram-бот с мини-приложением для обработки
заявок сотрудниками IT.

## Состав проекта

```
/index.php               — страница входа (ФИО + пароль)
/change_password.php     — смена пароля (обязательна при первом входе)
/dashboard.php            — создание новой заявки
/my_tickets.php           — «Мои заявки»
/all_tickets.php          — «Все заявки»
/ticket.php               — диалог по конкретной заявке
/api/                      — AJAX-обработчики веб-кабинета
/assets/                   — CSS/JS веб-кабинета
/config/config.php         — конфигурация (БД, токен бота, адрес сайта)
/includes/                 — общий PHP-код (БД, авторизация, Telegram API)
/db/schema.sql             — структура базы данных
/db/seed_employees.sql     — список сотрудников клиники (498 ФИО)
/storage/uploads/          — загруженные файлы/фото (создаётся автоматически)
/bot/webhook.php           — приём вебхуков Telegram-бота
/bot/setwebhook.php        — одноразовый скрипт установки вебхука
/webapp/                   — Telegram Mini App для сотрудников IT-отдела
```

## 1. Требования к хостингу

Проект рассчитан на самый простой shared-хостинг:
- PHP 7.3+ (проверено на 7.3.33) с расширениями: PDO/pdo_mysql, curl, gd/fileinfo, mbstring, json — на большинстве хостингов включены по умолчанию.
- MySQL 5.7+/8.0 или MariaDB 10.3+.
- Apache с mod_rewrite/mod_headers и поддержкой `.htaccess` (AllowOverride All).
- HTTPS обязателен — без него Telegram Mini App и webhook работать не будут.

## 2. Развёртывание

### Шаг 1. Загрузите файлы
Скопируйте **всё содержимое** репозитория в корень сайта (например, `public_html`)
любым способом — FTP, файловый менеджер хостинга или git.

### Шаг 2. Создайте базу данных
В панели хостинга (cPanel и т.п.) создайте:
- базу данных, например `itdesk`;
- пользователя БД с полными правами на эту базу.

Затем через **phpMyAdmin** импортируйте по очереди два файла:
1. `db/schema.sql` — создаёт таблицы;
2. `db/seed_employees.sql` — добавляет 498 сотрудников клиники.

(Файл `schema.sql` также сразу создаёт двух сотрудников IT-отдела —
Александра Вавилова и Никиту Павлова — с привязкой к их Telegram ID.)

Пароль по умолчанию для **всех** сотрудников: `123456789`.
При первом входе система обязательно предложит сменить пароль или
оставить пароль по умолчанию.

### Шаг 3. Настройте config/config.php
Откройте `config/config.php` и укажите:

```php
define('DB_HOST', 'localhost');       // хост БД (обычно localhost)
define('DB_NAME', 'itdesk');          // имя базы данных
define('DB_USER', 'itdesk_user');     // пользователь БД
define('DB_PASS', 'ваш_пароль');      // пароль БД

define('APP_URL', 'https://itdesk.вашклиника.ru'); // адрес сайта БЕЗ / в конце

define('TG_WEBHOOK_SECRET', 'придумайте-случайную-строку');
```

Токен бота уже прописан (`TG_BOT_TOKEN`), его менять не нужно.

### Шаг 4. Права на папку загрузок
Убедитесь, что папка `storage/uploads/` доступна для записи веб-сервером
(обычно права `755`/`775` уже достаточно; если нет — выставьте `775`).

### Шаг 5. Подключите Telegram-бота
1. Оба сотрудника IT-отдела должны один раз отправить `/start` боту
   (иначе Telegram не позволит боту первым написать пользователю).
2. Откройте в браузере:
   `https://ваш-сайт/bot/setwebhook.php?key=ЗНАЧЕНИЕ_TG_WEBHOOK_SECRET`
   (значение — то, что вы указали в `TG_WEBHOOK_SECRET` на шаге 3).
3. Должен появиться ответ `"ok":true` — значит, вебхук установлен.
4. После успешной установки рекомендуется удалить файл `bot/setwebhook.php` с сервера.

### Шаг 6. Настройте Mini App в BotFather (необязательно, но рекомендуется)
Через [@BotFather](https://t.me/BotFather) выполните `/mybots` → выберите бота →
`Bot Settings` → `Menu Button` → укажите URL: `https://ваш-сайт/webapp/`.
Тогда у сотрудников IT-отдела в чате с ботом появится кнопка быстрого
открытия панели заявок.

Готово — система полностью работает.

## 3. Как это устроено

### Сотрудники клиники (веб-кабинет)
- Вход по ФИО (с автоподбором) и паролю.
- «Создать заявку» — текст + вложения (фото/документы).
- «Мои заявки» — список своих заявок со статусами (открыта/закрыта).
- «Все заявки» — заявки всех сотрудников в режиме чтения (свои заявки
  выделены цветом), чтобы не плодить дубликаты обращений.
- Открыв заявку, сотрудник видит переписку в виде мессенджера и может
  дописывать сообщения с вложениями, пока заявка открыта.
- Если заявку закрыли, а проблема осталась — кнопка «Открыть заявку».

### IT-отдел (Telegram)
- При создании новой заявки обоим сотрудникам IT приходит сообщение
  «Новая заявка!» с кнопкой **«Забрать заявку себе»**.
- Нажатие кнопки закрепляет заявку за сотрудником и рассылает
  подтверждение обоим сотрудникам IT.
- Внутри бота доступно Mini App (кнопка «Открыть панель заявок» после `/start`,
  либо через Menu Button, либо кнопка «Открыть в приложении» в уведомлении):
  - **Новые заявки** — все открытые заявки; закреплённые помечены именем
    и цветом сотрудника (Александр — фиолетовый, Никита — голубой);
  - **Мои заявки** — заявки, закреплённые за текущим сотрудником;
  - **Закрытые заявки** — вся история закрытых обращений;
  - переписка по заявке — тот же диалог, что видит сотрудник клиники;
  - кнопка **«Закрыть заявку»**, при закрытии — чекбокс «Дежурство в
    выходные»; если отмечен — счётчик часов (по умолчанию 1 ч, ±1 ч кнопками);
  - кнопка **«Открыть заявку»** — возвращает закрытую заявку в работу;
  - пункт меню (⋮) **«Отчёт по дежурствам»** — часы по каждому сотруднику
    IT-отдела, сгруппированные по неделям.

## 4. Безопасность
- Пароли хранятся в виде bcrypt-хэшей.
- Папки `config/`, `includes/`, `db/` закрыты от прямого доступа через `.htaccess`.
- В папке `storage/uploads/` запрещено исполнение скриптов — только отдача файлов.
- Все запросы к БД выполняются через подготовленные выражения (PDO).
- Вебхук Telegram проверяет секретный токен (`TG_WEBHOOK_SECRET`).
- Подлинность данных из Mini App проверяется по HMAC-подписи Telegram (initData).

## 5. Обслуживание
- Резервные копии: делайте регулярный дамп базы данных (`mysqldump`) и
  архив папки `storage/uploads/`.
- Чтобы добавить новых сотрудников — просто добавьте строку в таблицу
  `users` (через phpMyAdmin) с паролем-хэшем (см. `db/seed_employees.sql`
  для примера) — по умолчанию используйте пароль `123456789`.
